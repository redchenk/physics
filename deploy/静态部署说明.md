# 物理站点的静态部署

现有站点由 1Panel OpenResty 提供静态文件。站点目录为 `/opt/1panel/www/sites/phy.yachiyo.email/index`，容器挂载其父目录。部署只替换物理站点的 `index`，不修改 nginx 配置、证书、其他站点或容器，也不在 2C2G 服务器上构建或增加常驻进程。

## 构建与上传

在本机运行 `npm ci`、`npm run verify`、`npm run build:static`。静态产物是 `dist/client/`。在提交代码后，向产物添加 `deployment.json`：

```json
{
  "release": "20261002-commit-prefix",
  "commit": "完整的40位提交哈希",
  "builtAt": "ISO时间",
  "files": {"index.html": "SHA-256", "每个其他产物的相对路径": "SHA-256"}
}
```

`files` 必须覆盖所有构建文件，不包含 `deployment.json` 自身。压缩产物内容，不要把上层 `client` 目录一起打包。使用现有 SSH 登录上传 tar.gz 和本目录的 `install-static.py`；凭据通过 SSH 认证提供，不写入仓库或归档。

在服务器执行：

```sh
python3 /tmp/install-static.py /tmp/physics-release.tar.gz 20261002-commit-prefix
```

安装器锁定物理站点的部署，验证归档路径和每个文件的 SHA-256，保留旧页面需要的 `_next` 资源及 ACME 文件，再用 Linux `renameat2(RENAME_EXCHANGE)` 原子切换目录。通过本机 HTTPS 检查首页和电学、光学关键资源；健康检查失败会立即交换回旧版本。成功后原站点完整保留在 `backups/index-before-发布编号`。

安装器同时比较所有现有 vhost 配置和其他站点首页的 SHA-256。它不 reload nginx；部署完成后应再从公网打开课堂入口、电学与光学，检查控制台、实验操作和首页引用的资源。

## 回滚

用安装器输出的准确备份目录替换下面的 `BACKUP`，在服务器执行：

```python
import ctypes, os
from pathlib import Path
SITE = Path('/opt/1panel/www/sites/phy.yachiyo.email')
BACKUP = SITE / 'backups/index-before-发布编号'
assert BACKUP.is_dir() and not BACKUP.is_symlink()
libc = ctypes.CDLL(None, use_errno=True)
libc.renameat2.argtypes = [ctypes.c_int, ctypes.c_char_p, ctypes.c_int, ctypes.c_char_p, ctypes.c_uint]
libc.renameat2.restype = ctypes.c_int
if libc.renameat2(-100, os.fsencode(SITE / 'index'), -100, os.fsencode(BACKUP), 2):
    raise OSError(ctypes.get_errno(), '回滚交换失败')
```

交换后重新检查站点；被回滚的新版本仍留在原备份位置，可再次交换恢复。不要批量清理其他网站或旧资源。浏览器中的实验数据不在服务器目录中，切换静态版本不会主动删除本地记录。

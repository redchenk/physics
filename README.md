# 格物 · 物理仿真实验与探究平台

面向课堂教学的交互式物理实验平台，提供声学、光学、电学、力学实验，以及学生探究与教师工作台。

在线体验：[phy.yachiyo.email](https://phy.yachiyo.email/)

## 实验内容

- **声学**：声音发生器、麦克风示波器、频谱与录制对比。
- **光学**：自由组合光路、平面镜成像、色散、反射与折射、透镜成像。
- **电学**：自由搭建电路、欧姆定律、串并联、伏安特性与电磁感应。
- **力学**：自由组合杠杆、滑轮、钩码和测力计，拖动挂点、连接绳索、观察力矩与拉力变化。
- **探究与教学**：预测、变量计划、实验记录、证据反馈、迁移验证和教师复核。

## 本地运行

需要 Node.js 22.13.0 或更高版本、npm 10 或更高版本。

```sh
npm ci
npm run dev
```

访问 <http://127.0.0.1:3001/>。Windows 安装依赖后也可双击 `启动应用.bat`，结束时双击 `停止应用.bat`。

麦克风采集需要浏览器授权，并在 localhost 或 HTTPS 环境下运行。学生记录默认保存在当前浏览器本地。

## 电学与光学操作

电学点击两个接线柱即可接线；在“选择元件或导线”中可直接选中对象，再查看属性、改参数或删除。选中导线后可拖动握柄调整整段线路；元件可拖动或用方向键微调。光学无需接线，把器材放进光路后即可观察；选中器材可调焦距、折射率、色散、尺寸，也可用圆形手柄旋转。

两种实验台均提供“适应窗口”、缩放和原始大小，手机端可展开器材盒，并通过“查看属性”访问参数。`Esc` 取消当前操作，`Ctrl/Cmd + Z` 撤销，`Ctrl/Cmd + Shift + Z` 重做。

自由电路、光学自由探索、平面镜成像与色散装置及其记录会自动保存在当前浏览器。用“保存电路与记录”或“保存装置与记录”导出完整 JSON，之后用“载入备份 / 载入装置”恢复。其他专题的记录仍需在刷新前导出 CSV。课堂演示与学生探究分别记录；教师工作台可导入探究证据 JSON，预览后合并，保留本机同 ID 会话与教学策略。多页面同时修改时会提示保存冲突，请先导出当前备份，再刷新。

## 验证与构建

```sh
npm run verify
```

包含类型检查、自动测试、代码检查和生产构建。也可单独运行 `npm test` 或 `npm run build`。

静态服务器使用 `npm run build:static`，产物位于 `dist/client/`，无需在服务器运行 Node.js。现有服务器的隔离部署与回滚步骤见 [静态部署说明](deploy/静态部署说明.md)，本次验证见 [操作优化验证](docs/操作优化验证-2026-10-02.md)。

## 代码结构

- `app/`：课堂入口、学生探究、教师工作台及平台界面。
- `electricity/`、`mechanics/`、`optics/`：各科物理模型与实验交互。
- 根目录的独立 HTML：可独立使用的课堂实验页。
- `scripts/sync-classroom.mjs`：构建时同步实验资源到 `public/` 和 `public/classroom/`。
- `tests/`：物理模型、交互与平台逻辑测试。
- `docs/`：设计说明及历次验证记录。
- `deploy/`：现有站点的部署配置示例。

平台采用 React、TypeScript 与 Vinext/Vite。实验使用教学近似模型，适用范围见各实验页面说明。详细操作参见 [本地运行说明](本地运行说明.md)。

本仓库不包含依赖目录、构建产物、本地运行日志或服务器凭据。

# 电学自由搭建验证

本次将课堂电学从固定演示扩展为可从空白开始的电路实验台。原有四个固定实验保留；独立 HTML、旧网页地址和平台内嵌入口共用 `electricity/` 的源代码。

## 完成的能力

- 电源、开关、电阻、三端滑动变阻器、定阻近似灯泡、电流表、电压表、分线点均可重复添加。
- 接线柱任意连线、分支、移动与旋转元件、删除导线/元件、撤销/重做。
- 直流电阻网络按真实拓扑求解，电流表串入的支路与电压表跨接的位置决定读数；识别短路、反接、浮空和超量程。
- 可编辑伏安法、串联、并联示例；手动记录并导出包含接线快照的 CSV。

## 自动验证结果

`npm run verify` 完成类型检查、85 项自动测试、代码检查及生产构建。其中 23 项新增电学测试覆盖：串并联与实际改接、分支和分线点、断开/闭合、极性与量程、错误串接电压表、浮空、直接短路及恢复、变阻器三端与零阻端点、多电源、平衡/不平衡电桥、功率关系、输入约束和资源副本一致性。

本地 HTTP 检查确认内嵌与旧地址的 HTML、计算脚本、编辑脚本和样式均返回 200，且脚本/样式使用相应资源类型。

本轮未执行浏览器交互或截图回归；拖动、触屏与键盘操作的视觉表现仍需实机复核。未部署线上站点。

## 教学模型边界

电源内阻 0.1 Ω、电流表内阻 0.01 Ω、电压表理想开路；导线与闭合开关理想。灯泡以定值电阻近似，未加入温升、交流或暂态。画面明确说明模型。不同独立连通分量之间的电压未知，显示“未接入”；电源短路时暂停读数。记录留在页面内存，刷新清除，导出可保存。

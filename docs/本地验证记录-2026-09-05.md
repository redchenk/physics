## 验证范围

本次执行了自动逻辑测试、构建和 HTTP / 启动器检查，没有执行浏览器点击/视觉验收，也没有采集真实麦克风或验证扬声器的主观听感。声音算法测试使用合成信号。正式课堂使用前，仍应在实际教室设备检查麦克风权限、音量、投影与浏览器交互。

当前诊断是本地规则驱动，覆盖两类探究策略与五类候选误概念。它保留自由文本和证据链供教师复核，不声称具备通用语言模型的开放式语义理解；班级同步仍为单机范围。

## 体验路径

1. 双击项目根目录的 `启动应用.bat`。
2. 默认“课堂实验”中打开声、光、电实验室，原有演示功能均保留；可在二级导航切换，或使用“单独窗口演示”。
3. 打开“教师工作台”，点击“载入演示班级”；选择学生，查看认知证据、过程画像，点击依据进入操作回放。
4. 切到“学生探究”，新建声、光或电任务；完成预测、方案、记录、结论与独立验证。
5. 声学会话进入实验后，切换二级导航的“声音采集与波形对比”，可把实时或 A/B 片段派生读数加入证据本。课堂自由演示不会自动进入学生档案。

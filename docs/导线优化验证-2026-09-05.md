# 导线重新优化 · 2026-09-05

## 完成的改动

- 重写布线器：按电气节点分配通道，共用线路在画面中合并，分支用实心圆点表示；不同节点交叉时使用跨线桥，避免长段重叠和贴接误读。
- 避让元件、标注和接线柱出口，增加弯折、交叉和相邻通道的代价，减少碎折线。交叉点与拐角保持距离，给跨线桥留空间。
- 保留不受影响的线路，移动一个元件时只重新规划受影响的路径。
- 点击导线高亮起终端，可拖动整段线路，也可用方向键微调；不合适的拖动回退。侧栏可切换同一节点中的不同接线，分别删除或恢复自动布线。
- 接线时可点击空白区域设置最多八个拐点，Backspace 撤回拐点，Esc 取消。支持教材电路图与圆滑导线切换。
- 撤销/重做保存电路及实际走向。“整理自动导线”保留手动指定的线路。
- 调整串并联示例的摆放，避免示例中的无关交叉；收紧水平元件标注间距。旋转电表时 A、V 字符保持正向。

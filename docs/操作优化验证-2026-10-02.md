# 电学、光学操作优化验证

本次从在线站点的实际操作和截图开始检查，保留现有课堂配色、教学模型及独立 HTML 入口。重点处理拖动、接线、缩放、参数修改和数据恢复；未改声学、力学的物理算法。

## 检查与修复

| 步骤 | 原有问题或边界 | 本次结果 |
| --- | --- | --- |
| 1. 电学：选中、接线、改变参数、记录 | 数字输入只在 change 后提交；缩放后拖动位移不对应；细导线难选；拖动中断可能残留 | 参数即时重新计算，离开输入框时合并为一次撤销；拖动换算实验台坐标并提交抬手终点；增加元件或导线选择入口；取消、失焦、切换时恢复装置 |
| 2. 光学：拖动、成像、色散、记录 | 手机难以看全实验台与属性；专题画布空白处也可能改动光源或物距 | 自动适应、可缩放、独立属性区与器材选择；拖动只从实际可拖对象开始；背景点击保持参数；新增 2f 凸透镜成像及凹透镜发散装置 |
| 3. 手机操作 | 器材盒过长、属性与实验台难同时访问、接线柱缩小 | 手机默认折叠器材盒，“查看属性”可到达参数；390 px 下无页面横向溢出；接线柱保留小符号，并有 36 px 点击区域 |
| 4. 备份与刷新恢复 | 自由装置刷新丢失；教师导出缺少对应导入；多个页面可能互相覆盖 | 自由电路与三种光学自由装置自动保存；完整 JSON 备份校验导入；教师预览后合并并去重；旧页面拒绝覆盖另一页面新数据 |

## 实际浏览器验证

- 电学：60 Ω 的伏安法装置读数为 0.100 A、5.989 V；断开开关或删除串联导线后为 0，撤销或重新连接后恢复。85% 缩放拖动元件可对齐网格，方向键可移动，撤销能复原。
- 电学：导入并联电路 JSON 后显示 6 元件、8 导线、0.298 A，导入前电路和记录可撤销恢复。装置和两组记录已验证刷新恢复。
- 光学：凸透镜 2f 起始装置的 5 条物体顶端光线在光屏同一点相交，透镜孔径设置在模型近轴范围内；将焦距 15 cm 改为 10 cm 后光屏出现分散落点，记录和装置可刷新恢复。
- 光学：棱镜拖动从水平 41 cm 到 45 cm，撤销回到 41 cm；B 从 0.009 改为 0 后红、紫折射率均为 1.52，光屏跨度从 2.22 cm 变为 0。
- 教师工作台：有效备份预览“新增 1 个”，确认后刷新仍能查看会话；重复导入预览“新增 0 个”，不覆盖本机策略或同 ID 记录。光学完整备份导入后为 0 组，撤销后恢复原有 2 组记录。
- 手机：390×844 检查电学、光学，无整体横向溢出；缩放后的完整光路、电路、读数与选择入口可访问。浏览器错误日志为空。

本机截图位于忽略目录 `outputs/design-audit/`：01–03 为优化前，04–08 为优化后。生产部署后的截图与 HTTP 检查应与本机结果一起验收。

生产验证：静态包经 SHA-256 校验后原子安装，74 个公开产物的 HTTP 内容与本地一致；两个隐藏构建元数据文件按现有 nginx 规则返回 403。其余站点的首页内容、全部 vhost 配置和运行中的容器保持不变，服务器未新增常驻进程。旧目录完整保留在物理站点的 `backups/`。在线入口与电学参数、记录、刷新恢复及光学成像已再次实测；线上截图接续保存为 09–11。

## 自动验证

`npm run verify` 通过类型检查、228 项测试、lint 和默认生产构建。新增测试覆盖导出 JSON 内容、导入后装置与记录一起撤销/重做、缩放拖动、抬手终点、取消/失焦、参数即时计算与撤销、合法与非法备份、多页面写入保护及两种光学起始装置。静态部署另用 `npm run build:static` 验证并输出 `dist/client/`。

GitHub 的 Verify 工作流在 main 推送和 PR 上执行同样检查及静态构建。

## 使用边界

- 自动保存以浏览器和站点来源为单位，不是服务器同步；跨设备请导出/导入 JSON。存储不可写、损坏或冲突时会明确提示，原数据不会被空白初始值覆盖。
- 自由电路、光学自由探索、平面镜成像和色散台保留装置与记录；电学其他专题、传统反射/折射/透镜专题仍应在刷新前导出记录。课堂演示不自动生成学生探究证据。
- 电学保持直流稳态与定值灯泡教学模型；光学保持几何光学和薄透镜近轴近似，大角度会提示模型限制。
- 桌面浏览器和响应式视口检查不能替代真实触屏设备验收，也未据此宣称完整无障碍合规。浏览器下载事件采集受测试工具限制；导入、恢复及生成数据的校验已验证。

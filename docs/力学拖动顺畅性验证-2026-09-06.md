# 力学连续拖动与局部改绳

## 复现与定位

用户再次报告钩码和绳索不自由、不顺畅。先在真实控制器事件入口建立四个失败回归：

- 指针从 x=430 移至 436.25 时，钩码被取整到 435；原实现每 5 像素跳格。
- 最后一次移动到 x=460、松手到 x=610 时，钩码仍挂在 `l1:s-1`，而不是最终位置的 `l1:s4`。
- 抓住原绳中段无法进入拖动；原处理器仅接收挂点和端点。
- 游离绳端移动 15 帧，试拉选择框被重建 15 次。原重画路径每帧调用完整求解、重画装置与所有结果控件。

按坐标处理、重复刷新、布局变化和命中/事件冲突的顺序排查，进一步确认：

- 原穿绳提示插入画布上方，消息区也会随文字增高。窄屏时按下器材重建属性栏，会进一步移动画布。新增属性栏写入回归先失败，再验证修复。
- 点击处理器查找最近的 `[data-mode]`，画布自身也有该属性，真实子元素点击会被错误识别为工具模式切换并取消连接。原事件夹具只匹配元素自身，遗漏了这一祖先匹配问题；本轮补了祖先匹配回归。
- 钩码挂钩透明命中区进入了本体区域；试拉后开始拖动会恢复试拉前位置。

## 最终行为

- 拖动保留指针的小数坐标，松手处理消费最终位置；吸附只作为候选提示，完成时才挂上。
- 自动挂接可关闭，Alt 可临时绕过；缩小远距离吸附区域，向下取下不再被原挂点强行吸回。候选挂点在一次拖动开始时缓存，保留轻微滞回以减少相邻挂点闪动。
- 绳中段可直接提起并绕入新增滑轮；轮上的绳段可直接拖开取下或改绕。局部操作保留两端与其他轮槽，仍由切线和连续圆弧确定最终绳形。无效改法保留原绳。
- 游离绳端只更新独立 SVG 预览层；器材拖动更新位置和绳几何，测量区淡化并说明完成后更新读数。松手后完整求解，预览期间禁止记录，避免保存未完成装置或旧读数。
- 穿绳条移到画布之后，消息区固定高度。按下和持续拖动期间保留属性栏，结束后更新，避免窄屏坐标跳动。
- 钩码本体增加透明命中区域，挂钩命中区域与本体分开；已有绳段有拖动光标与触控手势支持。
- 修复画布祖先属性误触模式；采用试拉后的当前位置开始编辑。取消、切换模式、撤销和离开页面清理未完成手势及绘制帧。

## 验证

`npm run verify` 通过：类型检查、181 项测试、静态检查、生产构建。力学测试共 48 项。

本轮新增 14 项回归覆盖小数坐标连续跟随、快速松手、绳中段开始拖动、测量控件保持、自动挂接开关/Alt、向下取下、拖开轮上绳段、绳中段增绕滑轮、试拉后移动、绳端最后松手事件、实际祖先匹配、60 帧独立预览更新、提示区顺序和窄屏按下时属性栏保持。

60 帧游离绳端事件回放中，装置 SVG 与试拉选择框均未重建，只更新预览层。该结果是事件和 DOM 写入次数验证，不是实体设备帧率测量。本轮未进行浏览器视觉验收或实体触屏测试；触屏覆盖为 `pointerType: touch` 的控制器事件回放。

没有遗留调试日志。物理计算未改变；既有绳、挂接及 JSON 格式保持兼容。避免此类回归的改进是将拖动预览与测量刷新分开，并在事件夹具中显式覆盖祖先匹配和指针松手坐标。

# 电学实验重做与验证

本记录对应灯泡发光示意、导线走向和四个专题实验的重做，接续此前的《电学自由搭建验证》。本次进行实际浏览器交互与截图检查；此前记录中的“未执行浏览器回归”仅指上一次改动。

## 实现

独立电学 HTML、平台内嵌页和旧地址共用 `electricity/` 资源。自由电路仍按真实接线求解；专题实验分别使用独立的物理模型、SVG 装置、表盘、测量图和记录表。

导线采用网格避障，优先避免重叠并减少折弯。元件旋转与滑动变阻器 W 端子的出口避开标注；新增元件选择不堵住已有导线的位置。选中的线路可通过菱形路径点调整，支持恢复自动、撤销和重做。密集布局无可用路径时以虚线明确提示，仍可移动元件或调整路径。

灯泡的光晕、光芒和灯丝颜色随计算功率变化，断路熄灭，并保留文字和功率读数。

## 实际浏览器验证

在本地应用中用可见页面操作和截图检查了以下流程：

| 场景 | 结果 |
| --- | --- |

| 自由并接电压表 | 任意添加电压表，将正负端跨接到灯泡两端，读数约 5.970 V |
| 调整导线 | 选中后通过方向键移动菱形，路径变化，5.970 V 读数保持不变 |
| 自动布线 | 观察并联示例的独立通道与交叉断口；新增电表不再堵住原有线路出口 |
| 欧姆实验 | 6 V、20 Ω、Rp = 0 时为 6 V / 0.300 A；Rp = 120 Ω 时为 0.857 V / 0.043 A；记录表保留两组测量 |
| 装置滑片 | 直接拖动 SVG 滑片后参数与读数更新；键盘微调同步；开关断开后表盘与数字归零 |
| 串并联 | 6 V、20 Ω 与 40 Ω 串联时电流均为 0.100 A，分压 2 V / 4 V；并联断开 S₁ 后 L₁ 熄灭，L₂ 保持发光且 I₂ = 0.150 A |
| 伏安特性 | 灯泡及定值电阻扫描均完成 41 点；停止扫描提示恢复。二极管 +0.8 V 时约 485.2 mA，−0.8 V 时显示接近零 |
| 电磁感应 | 静止归零；自动运动有带符号读数；对调磁极反号；开路电动势非零而电流为零 |
| 磁铁拖动 | 拖入线圈、从线圈内继续拖出均有效，释放后归零；随后启动反向自动运动仍有感应读数 |
| 浏览器错误 | 检查所测页面，未发现控制台 error |

## 模型与范围

自由搭建和串并联灯泡采用定阻近似；伏安特性灯泡使用 U = 10I + 80I³ 的稳态温升近似。二极管不模拟反向击穿。感应以每匝磁通量 Φ = ±BA·exp(−x²/2σ²) 计算 ε = −N(dΦ/dx)v，仅模拟磁铁移动引起的感应，忽略自感和运动反作用。上述说明均在页面可见。

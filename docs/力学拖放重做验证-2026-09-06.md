# 力学拖放与装置图重做

已发布：https://phy.yachiyo.email/#classroom/mechanics

## 原问题与原因

用户报告钩码无法拖动换位、滑轮无法自由穿挂、支架遮挡钩码。新增控制器指针事件回归先在旧版失败：已挂接钩码仍留在 `l1:s-2` 而未移到 `l1:s4`；挂钩到轮缘再到末端的拖动产生零根绳。

根因是旧控制器直接拒绝挂接子件的拖动，穿绳入口只处理指定模式下的逐点点击，原检查只覆盖了这些点击而漏掉用户实际的拖动动作。支架及钩码主体的尺寸也没有按挂点间距约束。

## 交付行为

- 拖动已悬挂钩码即可换挂点。拖动中临时取下，靠近挂点显示绿色落点与悬挂轮廓，松手吸附；空白处松手取下。
- 挂接检测使用画布坐标和父子关系，支持斜杠杆、同点叠挂、缩放画布与触屏指针，拒绝父子循环。键盘左右键也可改变挂点。
- 小三角支点可以拖动或键盘移动；杆身与钩码保持原实际位置，力臂及力矩随支点改变。
- 绳索可从空挂钩一笔拖出，经过各轮缘，放到另一挂钩完成。可暂停后继续、逐点点击、退回及取消。轮缘绕行自动确定，明确拖过上/下侧会保留该侧。
- 预设装置已有绳端可直接拖动改接，保留绳 ID。选中绳索后也有双端拖拽手柄、整绳重穿和单个滑轮取下。取消保留原装置。
- 绳索最终仍由真实公切线与连续轮缘圆弧生成，张力与位移按连接计算。重叠、占用轮槽和无效接法继续明确提示。
- 装置改为浅色绘图台，紧凑支架、窄钩码、黄铜色杆身与蓝色滑轮，扩大透明挂钩命中区域。新资源带版本查询，防止沿用旧缓存。
- 既有 JSON 装置、记录导出、撤销重做和原有物理计算继续兼容。

交互几何在 `mechanics/interactions.js`；真实指针控制器在 `mechanics/controls.js`；SVG 装置渲染在 `mechanics/drawing.js`。计算与交互、绘制分开，方便直接验证用户动作而非仅验证公式。

## 验证

`npm run verify` 通过：类型检查、142 项测试、静态检查及生产构建。力学测试 34 项。

新增回归覆盖鼠标拖挂、触屏事件、取消恢复、缩放坐标、支点拖动与键盘移动、已有绳端直接改接、整套四轮组连续重穿、松手续穿、退回与取消、绕行侧、占用轮槽与循环挂接。33 个常用倾角/挂点组合验证渲染支架边界不与钩码主体相交。

未执行浏览器视觉或实体触屏设备验收；上述触屏验证指 `pointerType: touch` 的控制器事件回放。相比旧版，回归覆盖了实际指针动作序列，不将公式或点击测试表述为拖动验证。

线上服务器 HTTPS 与外部 HTTPS 各核对 64 个公共文件的 SHA-256；另外核对 6 个带新版本查询的力学资源，均与验证后的构建一致。
